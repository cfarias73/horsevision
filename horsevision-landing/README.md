# HorseVision landing page

Landing page responsive en HTML, CSS y JavaScript vanilla.

## Abrir
1. Descomprime la carpeta.
2. Abre `index.html` en el navegador, o abre la carpeta en Visual Studio Code.
3. Para desarrollo local, puedes usar la extensión Live Server.

## Estructura
- `index.html`: contenido y estructura.
- `css/styles.css`: estilos responsive.
- `js/main.js`: menú móvil y año del footer.
- `assets/images/`: imágenes de referencia recortadas para la landing.
- `assets/logo/`: marca transparente basada en el logo geométrico compartido.
- `assets/icons/`: iconos SVG editables.

## Antes de publicar
- Cambiar los textos de precios por los planes y precios reales.
- Sustituir los enlaces de prueba/inicio de sesión por las rutas reales de la aplicación.
- Revisar los textos de funcionalidades para que coincidan exactamente con lo que ya está implementado.
- Las imágenes de dashboard y análisis son recortes de la referencia visual generada; reemplazarlas por capturas reales del producto cuando estén disponibles.
