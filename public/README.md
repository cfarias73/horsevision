# Public Directory · HorseVision

Esta carpeta contiene los recursos estáticos públicos para la marca, landing y aplicación:

- `logos/`: Logotipos en formato vectorial, animaciones Lottie (JSON), favicons e iconos en PNG de alta resolución.
- `assets/`: Imágenes de apoyo, fotografías de caballos, banners, certificaciones e infografías.
